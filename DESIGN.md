# GovCon Operator Design Direction

## Archetype

Procurement-grade command system.

GovCon Operator should feel trustworthy, compliant, capable, and official. It should help small businesses find opportunities, analyze bids, manage compliance, source suppliers, and track execution.

## User Feeling

The user should feel that the process is becoming legible and manageable.

## Visual Direction

- Opportunity search
- Compliance checklists
- Bid analysis
- Supplier sourcing
- Execution tracking
- Document-heavy workflows

## Token Direction

- Radius: 3px
- Density: compact
- Typography: institutional sans
- Palette: federal neutrals, white, deep green, slate, alert amber
- Icons: utilitarian line icons
- Motion: almost none; state changes should be obvious

## Avoid

- Startup gloss
- Flashy AI styling
- Playful icons
- Ambiguous status labels
- Dominant navy-by-default government cliche

## AI Prompt Recipe

```text
Design a government contracting operations platform for small businesses. Use procurement-grade tables, compliance checklists, document workflows, supplier records, and official-feeling status systems. It should feel trustworthy and operational, not flashy.
```

## QA Checklist

- Are compliance states unmistakable?
- Are document and source references visible where needed?
- Does the product feel serious enough for procurement work?
- Are AI features presented as analysis support, not magic?
